### Simple System

Comando reproduzivel:

```bash
make -C mini-SoC/experiments/riscv-core-qualification ibex-smoke
```

Resultado funcional observado:

```text
Hello simple system
Terminating simulation by software request.
Executed cycles: 13268
Cycles: 477
Instructions Retired: 261
```

Estado: **`SMOKE-PASS`**. O passe exige simultaneamente a mensagem do firmware
e o termino solicitado por software. Uma execucao exploratoria anterior reportou
13.274/478 ciclos, enquanto o alvo final reportou 13.268/477; os contadores sao
registrados como diagnostico, nao como oraculo de passe nem comparacao de
desempenho, ate que seed, configuracao, memoria e testbench sejam controlados.

## Croc/CVE2

Revisao Croc: `968bab17b37e88d9200a0899cb9181e42850ec87`.

O firmware e o RTL completo foram recompilados a partir de uma copia limpa. O
modelo Verilator foi gerado a partir de 211 modulos e a simulacao confirmou:

```text
[JTAG] ... escrita/leitura de 0x12345678 na SRAM
[CORE] Waking core via CLINT msip
[JTAG] Halting hart 0
[JTAG] Resumed hart 0
[UART] Hello World from Croc!
Illegal instruction (hart 0) at PC 0x00000000: 0x00010413
```

A mensagem de instrucao ilegal se repetiu ate o timeout e o marcador obrigatorio
`[JTAG] Simulation finished: SUCCESS` nao apareceu. Classificacao:

- firmware: **`PASS com adaptacao de toolchain`**;
- compilacao RTL: **`PASS`**;
- smoke de sistema: **`BLOCKED`**;
- testes `print_config` e regressao de perifericos: **nao executados**, pois o
  gate anterior ainda falha.

O valor `0x00010413` corresponde a uma codificacao RV32I valida (`addi s0,sp,0`),
logo a causa nao deve ser declarada apenas com base na mensagem. O proximo passo
e capturar PC, resposta da memoria de instrucao, trap cause e fluxo da boot ROM em
waveform, primeiro com a toolchain recomendada pelo upstream.

## Limite da evidencia

Esses resultados qualificam os caminhos executados, nao a CPU inteira nem o SoC
CHIPUS. Nao foram medidos cobertura, conformidade ISA completa, PPA, timing,
consumo, DRC, LVS ou comportamento com SRAM SKY130.
